type():- it is a library function of python to check datatype of any reference (variable).

syntax:- returns datatype= type(reference_name)

=> input() :- its a library function of python used to take input from user at runtime (dynamically).
syntax:-
return stringvalue()

=> typecasting:- it is a mechanism in which we convert one data type into another datatype. for typecasting python provide functions.
1. int():- numerical string/float into int 
2. float():- numerical string/int into float
3. str():- int/float into string

id():- it is a predefined function of pyhton. it returns unique memory address of given reference(Variable).
id value always unique during the lifecycle of program.

syntax:- 
return address = id(reference_name)

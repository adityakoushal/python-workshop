# tuple:- 
    tuple is a collection of same + different-different data type values.
1. tupple is also a constructor.
2. tuple is immutable or unchangable in nature.
3. tuple is same as list in terms of ordered , indexing and allow duplicate element.

=> syntax:-
    ref_var_name = (value1, value2, value3, ....)

# packing:- 
    the process of assigning value to a tupple is known as packing. pass multiple values to a single variable(*args)


exp. => reference = (value1, value2, ....)

# unpacking in tuple:- 
    to extract the values of a tuple into a single variable is called unpacking.
* syntax=> (value1, value2,....) = reference_name

* Note:- the number of variables must match the number of values in the tuple, if not you must use an asterick to collect the remaining values in a list.

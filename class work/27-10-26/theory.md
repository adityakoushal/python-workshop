# types of operators

1. Arithmetic operators
=> +, -, *, /, %

==================================================================

2. Additional operators
=>  ** exponential operator
=>  // floor division operator

==================================================================

3. relational operator
=> >,<,<=,>=, == , !=

==================================================================

4. logical operator
a. and:- minimum 2 condition must be given and all the given condition must be true.

b. or:- minimum two condition must be given and from all the given condition only one condition must be true

c. not:- minimum 1 condition must be given and it is set true to false and false to true

==================================================================

5. identity operator:- identity operator used to compare address of given references.
a. is :- if both references/addressess are same it return true otherwise false
b. is not :- if both references/addressess are different it return true otherwise false

==================================================================

6. Membership operator:- it is used to search given data in a collection.
a. in :- if search data is exists it returns true otherwise false
b. not in :- if search data does not exists it returns true otherwise false

==================================================================

7. bitwise operator :- & bitwise and
                     | bitwise or
                      ^ bitwise xor
                      << bitwise left shift
                      >> bitwise right shift
